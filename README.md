# RANGE LAB

面向《无畏契约》玩家的独立网页 3D 战术训练场，练习移动停稳、短点射、头部瞄准和预瞄清角。首版为单人本地训练，无账号或后端。

## 快速使用

需要 Node.js 22.12+、npm，以及支持 WebGL 2 和 Pointer Lock 的桌面浏览器。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

浏览器打开 http://127.0.0.1:5173 。选择训练模式后点击开始。

| 操作 | 输入 |
| --- | --- |
| 移动 | W / A / S / D |
| 调整瞄准 | 鼠标 |
| 射击 / 自动连射 | 点击 / 按住鼠标左键 |
| 换弹 | R，空弹匣继续射击也会自动换弹 |
| 慢走 | Shift |
| 暂停并释放鼠标 | Esc |

移动端可以浏览场景、设置和记录，触屏设备不能进入键鼠训练。

## 训练模式

- 急停点射：每次击杀前需要累计移动至少 0.65 米，并在实际速度不超过 1.485 米/秒（最高移速的 27.5%）时开枪。未满足条件的弹着仍计入命中率，但不造成伤害或计入击杀。
- 精准点射：不同位置与距离的目标，头部 160、身体与手臂 40、腿部 34 伤害，目标总生命值 150。
- 预瞄清角：三组实体掩体，子弹和玩家均受遮挡；记录移动中目标首次进入视野时的准星角度偏差。
- 60 / 120 / 180 秒训练，三档目标难度，结算、枪口角度分布和最近 30 轮记录。最佳命中率只计入至少射击 10 发的训练。

## 武器与音频

默认使用 PC 狂徒腰射配置：25 发弹匣、9.75 发/秒、2.5 秒换弹、首发散布 0.25°、站立连射最大散布 1°，走射与跑射另加最多 3°、6°。备用弹药无限。前 6 发限制横向切换，后续采用随机方向状态；镜头抖动和实际弹道上抬分离，连射不能只靠屏幕中心瞄准。

基础数值已对照社区 Wiki 和武器数据接口。逐发后坐力幅度、散布插值、长连射恢复和随机判定时钟仍是近似，尚未与原版逐帧校准。可核对值与假设见 [狂徒校准记录](docs/vandal-calibration.md)。核心参数位于 `src/model.ts`，后坐力状态位于 `src/vandal.ts`；后坐力强度 1 为当前默认曲线。

默认枪声采用公开社区狂徒录音的 3 个单发片段，随页面本地加载，保留原始音高。加载失败时使用程序合成备用音效。设置中可试听，也可导入本地单发枪声（最多 5 MB、5 秒）；导入文件仅在本页内存中使用，不上传。素材来源及使用边界见 [音频来源](public/audio/vandal/SOURCE.md)。

鼠标灵敏度系数使用每计数 `0.07 × sensitivity` 度的近似换算。操作系统加速、浏览器和 DPI 会影响实际手感，需要与游戏实测比对；首版未提供自动 cm/360 校准。

## 开发与验证

```sh
npm test
npm run build
npx playwright install chromium
# 另一个终端保持开发服务器运行
npm run test:e2e
```

使用已有浏览器时，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定可执行文件。逻辑测试额外检查不同帧率下的狂徒射速、点按冷却、散布边界、后坐力恢复与音频起音。浏览器测试检查真实画布像素、桌面/移动端截图、射击、移动、遮挡、换弹、暂停、计时结束、录音播放、音频回退及成绩保存。

构建产物为 `dist/`，可以部署到支持 HTTPS 的静态站点。当前只启动了本地服务，未发布公网网站。

## 依赖与结构

- Three.js：场景、原创几何枪械与目标、光照和射线命中。
- Rapier：实体碰撞和运动学角色控制器。
- Web Audio：合成音效、本地音频解码和多发播放。
- TypeScript、Vite、Lucide：应用、构建和图标。当前界面使用原生 DOM，没有引入 React 状态层。
- `src/scene.ts`：场景与碰撞；`src/game.ts`：固定步长模拟；`src/model.ts`：训练规则；`src/vandal.ts`：狂徒射击与恢复状态；`src/audio.ts`：声音调度；`src/vandal-sound.ts`：备用合成音；`src/main.ts`：界面与持久化。

设计与边界见 [DESIGN.md](DESIGN.md)。实现导航、功能迭代与验证流程见 [开发文档索引](docs/README.md)，编码助手入口见 [项目 skill](skills/range-lab-development/SKILL.md)。

## 随机闪光躲避

在训练设置中开启「随机闪光躲避」（默认关闭），三种模式均可叠加。橙色空间闪光源和提示音出现后约 0.8 秒爆闪；灰色半透明遮罩、闪光图标和剩余秒数表示致盲。暂停冻结闪光计时，重开清空本轮数据。

结算包含闪光次数、背闪成功、未躲过、掩体阻挡、背闪成功率、平均背闪反应与累计实际致盲秒数。未爆炸的闪光不计次数，掩体阻挡不进入背闪成功率分母。反应时间是从提示出现至最后一次持续背闪的时间。

此版本参考无畏契约的朝向减免机制，使用统一训练近似，不代表所有角色或某个版本的原版闪光。具体参数、空间判定、统计口径和扩展入口见 [闪光训练](docs/flash-training.md)。提示音为合成音效。
