## 明确属于近似的部分

- 公开资料没有逐发垂直后坐力角度表。`RECOIL.riseDegrees` 使用前段上抬、后段收敛到约 7.4° 的手工曲线。后坐力设置值为 1 时采用该曲线，跑射与训练自定义倍率另算。
- `0.6 秒 / 10%` 未公开完整概率判定时钟和内部实现。本项目解释为进入横向阶段后，距离上次切换至少 0.6 秒才允许每发进行一次 10% 判定；切换后重置计时。横向角度幅度与插值速度是手工近似，不能宣称已复现官方随机过程。
- 连射散布从 0.25° 到 1° 的增长曲线为幂函数插值。基础恢复时间 0.375 秒，但长连射按热度延长，最多 0.675 秒；此延长公式未经逐帧实测。点按未完全恢复时保留热度和后坐力，不再直接清零。
- 腰射的镜头后坐力与子弹方向分离：镜头垂直分量最多约 2.1°，子弹继续上抬并横向漂移；镜头比例、上限与枪模摆动幅度是近似。玩家可通过下拉鼠标补偿弹道，准星不会自动追踪整段弹道。
- 散布按圆盘均匀取样，再通过 `tan(angle)` 形成射线。未实现原版站立射击可能存在的中心偏置采样分布。
- 慢走速度 3.24 米/秒、加减速曲线、水平 FOV 换算和鼠标灵敏度仍需要与真实设备测量对齐。
- 静态训练场不模拟穿墙伤害、ADS、蹲跳、受击减速或技能加速。150 生命值用于模拟满甲击杀弹数，未单独模拟护甲吸收过程。

## 射速与反馈

`ShotCadence` 区分新的鼠标按下和按住扳机：连续射击保留理想出弹时间，新的点按必须等上一次实际射击的冷却，避免过期排程导致两发间隔过短。音效使用同一出弹时钟映射到 Web Audio 时间轴，正常帧率下保持连射节奏，失焦后重新对齐。

结算角度分布表示子弹相对当前鼠标瞄准方向的后坐力与散布偏移，不是固定墙面弹着坐标，也不记录玩家压枪轨迹。右为正 X，上为正 Y。旧版历史记录保留，但不参与当前狂徒配置的最佳命中率。

## 音频

默认使用 3 个公开社区录音中的单发片段，来源和处理见 [音频来源](../public/audio/vandal/SOURCE.md)。加载或解码失败时自动回退到程序生成的 8 种爆裂噪声变体。用户导入音频优先于默认录音，恢复按钮返回默认音源。

备用合成声音包含高频起音、中低频爆裂、短促机械瞬态与低音量早期反射；不再使用旧版明显的正弦扫频枪声。音频请求只访问本地静态文件，试玩时不请求第三方音频网站。

## 验证边界

自动测试检查 60 / 120 / 144 / 240 Hz 模拟下的出弹时间、点按冷却、散布边界、恢复状态、随机切换窗口、参考 WAV 的解码和起音、备用波形峰值，以及浏览器实际播放调度。未进行与原版的人工盲听对比、鼠标 cm/360 实测或逐帧弹道比对，不能量化整体还原度。
