# 随机闪光躲避

## 当前范围

三种模式可叠加，设置名 `flashEnabled`，默认关闭。采用无畏契约常见的朝向减免思路；这是统一训练模型，没有绑定具体角色、技能或原版版本，也没有实测还原度结论。

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `FLASH.fuse` | 0.8 秒 | 提示出现至爆闪的训练时间 |
| `FLASH.fullDuration` | 2 秒 | 正面致盲 |
| `FLASH.backDuration` | 0.3 秒 | 背闪残留致盲 |
| `FLASH.backAngle` | 100 度 | 相机前向与指向闪光源方向的夹角达到此值即背闪 |
| `FLASH.minGap/maxGap` | 6 / 11 秒 | 首次等待范围；后续从致盲结束起等待 |

`evaluateFlash` 优先判定掩体阻挡，致盲为 0。无遮挡时，夹角不超过 45 度使用完整时长；45 至 100 度线性减弱；达到 100 度为背闪。时长减弱但未达到背闪阈值仍记作 `hit`。

## 空间与时序

`Game.updateFlash` 到达 `nextAt` 后，在生成时玩家水平朝向左右约 31.5 度内选取位置，距离 4 至 7 米、高度 2.2 米，并限制在场地坐标边界内。当前为静止橙色多面体，随引信进度放大并旋转；不是投掷飞行轨迹，不会追随转身后的镜头。

每个固定步计算相机前向夹角，并对常驻场景实体和当前有效清角掩体做射线遮挡检查。爆闪瞬间的朝向与遮挡决定结果；提前转身又转回可能失败，爆闪后才转身不能消除已经确定的致盲。目标身体不参与闪光阻挡。

`FlashTrial` 负责等待、预警、爆闪记录和衰减。`Game` 决定何时调用 `begin`；该方法本身不是生成器。训练剩余时间不足一个引信周期时，不再生成新闪光。结束前尚未爆闪的预警不计入成绩。

当前生成器只限制场地边界，没有避免生成在掩体后或与实体重叠；掩体后爆闪会进入 `blocked`。声音是非空间化合成提示，在开始预警和爆闪时播放，受现有音量与静音设置控制。

## 视觉反馈

`main.update` 在 HUD 的 60 ms 节流之前更新 `blind-overlay`，使遮罩随渲染帧淡出。背景固定 RGB `(110, 114, 119)`，完整致盲透明度上限 0.76，背闪上限 0.3；最后最多 0.65 秒线性衰减。Lucide `Zap` 图标附剩余秒数，不使用白屏，遮罩不拦截鼠标。

暂停隐藏遮罩但冻结状态，继续后恢复剩余致盲；重开重置调度、致盲和记录。完整致盲仍保留场景可见性，这是用户指定的灰色透明表现。

## 统计口径

每次爆闪生成 `FlashResult`：`time` 为训练秒数，`angle` 为角度，`outcome` 为 `back/hit/blocked`，`duration` 为判定时长，`reaction` 为秒或 null。

| 结算项 | 计算 |
| --- | --- |
| 闪光次数 | 已爆闪结果总数 |
| 背闪成功 / 未躲过 / 掩体阻挡 | 分别统计 back / hit / blocked |
| 背闪成功率 | back / (back + hit)，无有效分母显示 `--` |
| 平均背闪反应 | 仅成功背闪的非空 reaction，转成毫秒；无样本显示 `--` |
| 累计致盲 | 每一步训练时间区间与致盲区间交集的总长度 |

`backSince` 记录最近一次持续满足背闪条件且无遮挡的起点，中途不满足则清空。反应时间是该起点减去预警时间，不是原始鼠标开始转动的时刻；如果预警一开始已背对，它可能接近 0。

累计致盲不直接相加判定 duration，提前结束不会计入未经历的尾段。到时自动结算先于最后一次闪光 step，边界最多有一个固定步的计数误差。历史列表展示背闪次数 / 全部闪光次数，分母含阻挡，与结算成功率的分母不同。

## 验证与扩展

纯逻辑覆盖见 `tests/flash.test.ts`；真实场景、灰色遮罩、背闪、暂停、重开和设置持久化见 `tests/browser/game.spec.ts` 的 `random flashes` 用例。掩体布尔判定已做单元测试，但该浏览器用例没有覆盖真实几何体阻挡；修改空间生成或射线逻辑时应补场景验证。

调整角色模型时把引信、正面/背闪时长、角度曲线分开定义，并记录来源。增加投掷轨迹、距离衰减或技能种类需要对应更新生成器和测试，不能只修改 UI 标签。测试命令与场景调试数据见 [迭代与验证](iteration.md)。
