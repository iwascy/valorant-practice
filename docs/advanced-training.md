# 准星、移动目标与背闪回瞄

## 实现入口

- `src/crosshair.ts`：分享码解析与 Canvas 2D 绘制。预览与 HUD 共用渲染器。
- `src/bots.ts`：可注入随机源的运动状态机、动静目标统计。
- `RangeScene.configureBots/updateBots/targetSpaceFree`：出生轴、移动、掩体、碰撞和复活检查。
- `src/reaim.ts`：回瞄状态与汇总；`Game.updateFlash/updateReaim/shoot` 接入。
- `src/main.ts`、`index.html`、`src/training.css`：设置、预览、结果与历史。

## 准星分享码

设置中粘贴分享码，点击上传图标应用；恢复图标只清空导入准星，恢复默认设置清空全部设置。有效原码保存在 `range-settings.crosshairCode`，刷新后重新校验；无效输入不覆盖当前准星。

支持版本 `0` 的 `P` 腰射段：颜色 `c/u`、描边 `h/t/o`、中心点 `d/z/a`、连射上方线淡出 `f`。内外线前缀 `0/1`，后缀 `b/a/l/v/g/t/o/m/f/s/e` 分别表示启用、透明度、横长、竖长、独立竖长、粗细、偏移、移动误差、射击误差及两个倍率。`P;s` 为观战偏好，单人训练不应用。

解析分号字段对及 P/A/S 段，最长 4096 字符；已知字段检查数值范围、类型和重复项，颜色只接受十六进制。未知 P 字段提示未应用；ADS/狙击段保留原码并提示只应用腰射，不宣称全格式兼容。不执行代码、HTML 或任意 CSS。

基础语义参考 [公开 Decoder 字段表](https://github.com/faheem-s27/ValorantCrosshairParser/blob/bb4701ccbb0b87e584c604ea8d698ea75284ad9d/Decoder.json)，仅核对协议含义，未引入源码依赖。没有使用官方解析 SDK。动态扩张、淡出曲线与缩放是近似，不能作为原版 1:1 校准结论。

预览画布为 160 CSS 像素，HUD 为 320 像素以容纳最大动态扩张，均最多 2 倍像素密度，线条仍按同一像素单位绘制。移动误差跟随超过精度阈值的速度，射击误差跟随热度，只改变准星表现。导入后禁用旧尺寸滑块，避免两个设置覆盖。浏览器缩放会影响实际显示尺寸。

## 机器人运动

`botMode` 为 `static/depth/strafe/mixed/peek`，默认静止。`botSpeed` 为 0.5 至 5.4 m/s、默认 3.24；`botRange` 为出生点轴向半径 0.5 至 4 m、默认 2。三种训练模式均可叠加，开局快照运动设置。

非静止目标保持标准体型，难度仍影响初始距离/点位。前后轴固定为出生点指向玩家初始位置 `(0, 8)`，左右轴垂直；玩家转身不会旋转轨道。混合模式随机更新两个方向的目的地，总速度受上限约束。

普通移动每 0.35 至 1.55 秒决定目的地，25% 概率进入减速停顿。加速度上限为 30 m/s²，接近目的地平滑减速；这些是训练参数，不是原版 AI 参数。

随机出角使用五个独立实体掩体，替代原清角掩体。状态为等待、出角、停留、返回；各自随机选择左右、2 至 2.65 m 距离、0.15 至 0.8 秒停留，返回后等待 0.6 至 2.6 秒。出角距离不使用移动半径滑块，选中时禁用该滑块。遮挡来自真实几何体；绕过掩体可以看到等待中的机器人，不通过隐藏模型伪造出角。

目标使用水平 0.4 m 余量对实体 AABB 检查，拒绝进入障碍物或其他目标；玩家不能继续走入机器人位置。掩体由 Rapier 阻挡玩家，子弹和闪光共用 `obstacles()`。出生点被占用时延迟 0.2 秒重试。碰撞适用于当前轴对齐场景，没有骨骼动画和全局寻路；新增旋转墙体或复杂地形需重新评估。

暂停冻结动作；恢复保留目标速度与阶段，重开/复活重置动作和交战起点。`generation` 每次重置递增，以区分同一模型的不同生命。

## 动静目标统计

`Session.targetShots/targetKills` 保存样本。命中归属实际受击目标；脱靶归属相机前向 30 度内、头部无遮挡且角度最小的存活目标。没有候选时为未归属射击，仍计入全局命中率，不进入动/静靶分母。该归属是估计，不能推断玩家真实意图。

目标实际速度大于 0.1 m/s 计为动靶，否则静靶。移动模式中的机器人停下时也计入静靶。命中率 = 命中 / 归属射击（含脱靶）；爆头占比 = 头部命中 / 全部命中，不是击杀爆头率。

击杀按致命一发时的目标状态分组。交战耗时 = 击杀时间 - 本次生命第一次归属射击时间，包含归属脱靶；首发击杀可为 0 ms，不是出现至击杀反应时间。无样本显示 `--`。

## 背闪后重新瞄准

预警生成时按上述可见目标规则锁定索引与 generation。仅最终成功背闪、目标仍存活且未复活时建立样本；无可见目标、正面闪或掩体阻挡不建立样本。

从爆闪时刻计时（包含 0.3 秒残留致盲）。朝向锁定目标头部 2 度内且无遮挡持续 80 ms，记第一次重新瞄准，以稳定区间起点计时。记录首个实际发射子弹是否命中锁定目标，以及随后击杀该目标的时间；空弹、换弹点击不计首发，命中其他机器人不算完成。

样本最长 5 秒；目标死亡/换代、训练结束或超时关闭活动样本，保留已发生的瞄准与首发结果。未开枪为 null，不作为脱靶；未击杀计未完成。平均耗时只含相应已完成事件，同时展示样本数、完成数和未完成数，避免把失败记为零。

历史保存 `botMode/targetStats/reaimStats` 摘要，旧记录可缺省；展示可选字段前检查类型。`ReaimTrial.reset` 替换数组，已结束 Session 的回瞄结果不会随重开清空。

## 验证

`tests/training.test.ts` 覆盖解析、错误输入、设置兼容、运动边界、出角阶段、统计分母及回瞄超时/换代。浏览器 `crosshair codes` 检查颜色像素、失败保留、刷新和手机布局；`bots` 检查真实画面、运动、出角、暂停恢复与历史；`random flashes` 覆盖背闪转回后的瞄准完成。完整回归仍包含原射击、遮挡、换弹与自动结束。
