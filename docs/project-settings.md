# 项目配置与语言

## 配置归属

`src/preferences.ts` 定义两层配置，`main.ts` 将两者合成为兼容游戏的 `Settings`。全局偏好只保存语言、灵敏度、FOV、音量和准星；训练时长、难度、弹药、目标行为、闪光、后坐力强度和教学提示按项目独立保存。

大厅的项目配置按钮编辑当前选中项目。右上角设置按钮打开全局偏好。切换项目重新加载该项目配置并更新预览，恢复项目默认不修改其他项目或全局偏好；恢复全局默认保留语言选择和项目配置。

| 项目 | 允许的目标行为 | 默认及限制 |
| --- | --- | --- |
| 急停点射 | static / strafe | 默认静止；轻度横移默认 1 m/s、半径 1 m，上限均为 1.5 |
| 精准点射 | static / depth / strafe / mixed | 默认静止；移动速度默认 3.24 m/s、半径 2 m |
| 预瞄清角 | static / peek | 主动清角 / 架枪等出角；独立掩体场景 |

静止目标隐藏速度和半径；随机出角隐藏半径和难度，因为其掩体与标准体型固定，难度规范为 normal。其余移动目标保持标准体型，难度影响出生点位/距离。每项训练均可独立开启随机闪光。

随机出角提供 `peekSide`（random/left/right，按玩家初始朝向）及 `peekInterval`（0.5–4 秒，默认 1.6 秒）。间隔指回到掩体后下一次出角的平均等待时间；实际取配置值的 0.375–1.625 倍。首次出角仍使用原来的 0.4–1.9 秒准备延迟。出角保持时间和探出距离沿用原规则。

## 弹药和会话

标准弹匣 25 发，备弹无限；`infiniteAmmo` 开启后弹匣不消耗，HUD 显示无限符号，手动/自动换弹无效。射速、散布、热度、随机后坐力和恢复完全沿用同一武器状态，超过 25 发不会重置连射。

`Game.start` 再次校验项目配置并复制到 `Session.config`。机器人、闪光、弹药、后坐力和提示使用本局快照。语言、准星、音量、灵敏度与 FOV 可即时应用。暂停、恢复、重开和训练时钟语义不变。

结算和历史记录保存完整配置、`configKey`，显示训练条件与玩法。主动清角显示出角偏差；架枪等出角不把玩家出角偏差当作其训练指标。最佳命中率要求至少 10 发、相同武器 profile、相同项目和完整项目配置键。旧记录没有配置键，仍可查看，但不参与新最佳值比较。配置键保守包含未启用行为的参数，因此不自动合并这些条件相近的记录。

## 存储迁移

新键为 `range-preferences`，版本 `2`，包含 `language/global/projects`。每个项目通过 `sanitizeProject` 校验枚举、数值、布尔值与行为限制；全局沿用准星解析及数值校验。

没有 v2 设置时，从旧 `range-settings` 迁移灵敏度、FOV、音量和准星。旧版全局训练行为不复制到三个项目，避免继续传播冲突；三个项目各自恢复默认。旧存储不删除，新设置在用户修改时写入 v2。历史键 `range-history` 不变。旧历史里的配置展示前也经过校验。

## 中英文

`src/i18n.ts` 管理中文源文案、英文词典与带运行时数值的模板。首次按 `navigator.language` 选择中文或英文，此后使用保存值。HTML 的 `lang` 同步切换。

原生 DOM 本地化绑定保留源文本，监听新增节点、文本变化及 title/aria-label/placeholder，切换语言不替换控件节点或清空状态。渲染时断开观察以免自身写入形成循环，并清理已移除节点。游戏状态判断必须依据数据，不能依据已翻译的 `textContent`。准星代码、textarea 和 `data-no-i18n` 本地文件名保持原样；所有显示仍使用文本节点，不解释输入为 HTML。

新文案加入 `messages`；带数值的完整句子加入 `templates`，由 `translate` 处理，组合摘要使用 ` · ` 分隔。变更后检查全局/项目设置、HUD、错误、结果、历史及可访问属性。日期新建显示时使用选定 locale，已经打开的历史日期格式在重新打开后更新。

## 验证入口

- `tests/preferences.test.ts`：旧配置迁移、项目隔离、校验、条件键、英文动态文案和出角方向。
- `tests/browser/preferences.spec.ts`：配置切换/恢复/刷新、中英文切换、英文错误与成绩、手机布局、连续超过 35 发且保持射速与后坐力。
- `tests/browser/game.spec.ts`：原有换弹、急停、闪光、目标移动、准星、音频、掩体和自动到时结算。

浏览器回归默认使用中文 locale；英文通过设置切换测试。开发环境真实画布像素与截图用于确认渲染，不把 DOM 存在当作场景可见。
